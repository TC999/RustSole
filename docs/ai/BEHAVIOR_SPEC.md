# BEHAVIOR_SPEC:行为规格

> 本文件是用户可见行为的唯一依据。每条规格有稳定的 ID,测试和提交信息用 ID 引用。
> 标注 **【待核实】** 的条目来自对 Konsole 默认行为的记忆,**必须**由用户对照真实 Konsole 确认后才能移除该标记。AI 不得自行将其视为定论。
> 规格缺失时,AI 先提问,不得自行补充规则。

## 1. 选择缓冲区(SEL)

选择缓冲区(下称"选区缓冲")与系统剪贴板是两个独立通道。

| ID | 规格 |
|---|---|
| SEL-001 | 左键拖拽选中文本,**左键抬起时**把选中文本写入选区缓冲,不写入系统剪贴板。 |
| SEL-002 | 中键点击终端区域,粘贴选区缓冲的内容(经过 PASTE 规则处理)。 |
| SEL-003 | 取消选区高亮(如点击空白处)**不清空**选区缓冲;之后中键仍粘贴上一次选中的内容。 |
| SEL-004 | 选中结果为空字符串时,不覆盖选区缓冲中已有的内容。 |
| SEL-005 | 键盘扩展选区(如 `Shift+方向键`)后,同样写入选区缓冲。【待核实】 |
| SEL-006 | Linux:选区缓冲使用系统 PRIMARY selection,可与其他应用互通(在本终端选中 → 在浏览器中键粘贴,反之亦然)。 |
| SEL-007 | Windows:选区缓冲为应用内缓冲,同一进程内所有窗口、标签共享。 |
| SEL-008 | 设置项 `copy_on_select`(默认关闭):开启后,选中时**额外**写入系统剪贴板。选区缓冲行为不变。 |
| SEL-009 | 单击拖拽为普通选择;双击选词;三击选行。 |
| SEL-010 | `Ctrl+Alt` + 拖拽为块(矩形)选择。【待核实】 |
| SEL-011 | 双击选词时,词内额外包含的字符为:`@-./_~?&=%+#`(便于选中 URL 与路径)。【待核实】 |
| SEL-012 | 复制出的文本去除每行行尾空格;被换行折断的软换行行不插入换行符。【待核实】 |
| SEL-013 | 拖拽到终端区域边缘外时自动滚动并持续扩展选区。 |

## 2. 粘贴(PASTE)

剪贴板粘贴与选区缓冲粘贴共用**同一个**粘贴处理函数。

| ID | 规格 |
|---|---|
| PASTE-001 | 换行规范化:`\r\n` 与 `\n` 统一转换为 `\r`。 |
| PASTE-002 | 程序开启 bracketed paste 模式时,用 `ESC[200~` 与 `ESC[201~` 包裹粘贴内容。 |
| PASTE-003 | 未开启 bracketed paste 且文本含换行时,弹出确认对话框(可在设置中关闭)。【待核实】 |
| PASTE-004 | 无论是否开启 bracketed paste,粘贴内容中的 ESC(`0x1b`)一律移除,防止提前结束括号粘贴序列。 |
| PASTE-005 | 移除其他 C0 控制字符,仅保留 `\t` 及换行。【待核实】 |
| PASTE-006 | 粘贴内容不得被写入日志。 |

## 3. 鼠标与程序交互(MOUSE)

| ID | 规格 |
|---|---|
| MOUSE-001 | 程序开启鼠标上报(如 vim `mouse=a`、tmux、htop)时,鼠标事件交给程序,终端不做选区/粘贴。 |
| MOUSE-002 | 按住 `Shift` 时,忽略鼠标上报状态,由终端自己处理选区和粘贴。 |
| MOUSE-003 | 滚轮:主屏幕滚动回看;备用屏幕且程序未接管鼠标时,转换为方向键序列。【待核实】 |
| MOUSE-004 | 中键点击标签栏上的标签 = 关闭该标签;中键点击标签栏空白处 = 新建标签。【待核实】 |
| MOUSE-005 | 双击标签栏空白处新建标签;双击标签重命名。【待核实】 |

## 4. 快捷键(KEY)

| ID | 规格 |
|---|---|
| KEY-001 | `Ctrl+Shift+C`:复制到系统剪贴板。 |
| KEY-002 | `Ctrl+Shift+V`:粘贴系统剪贴板。 |
| KEY-003 | `Shift+Insert`:粘贴选区缓冲。【待核实】 |
| KEY-004 | `Ctrl+C` 在终端内始终发送中断字符,不用于复制。 |
| KEY-005 | 方向键在应用光标模式(`APP_CURSOR`)下发送 `ESC O A/B/C/D`,否则发送 `ESC [ A/B/C/D`。 |
