# BEHAVIOR_SPEC:行为规格

> 本文件是用户可见行为的唯一依据。每条规格有稳定的 ID,测试和提交信息用 ID 引用。
> 标注 **【待核实】** 的条目来自对 Konsole 默认行为的记忆,**必须**由用户对照真实 Konsole 确认后才能移除该标记。AI 不得自行将其视为定论。
> 规格缺失时,AI 先提问,不得自行补充规则。

## 1. 选择缓冲区(SEL)

选择缓冲区(下称"选区缓冲")与系统剪贴板是两个独立通道。

| ID | 规格 |
|---|---|
| SEL-001 | 左键拖拽选中文本,**左键抬起时**把选中文本写入选区缓冲,不写入系统剪贴板。 |
| SEL-002 | 中键点击终端区域,粘贴选区缓冲的内容(经过 PASTE 规则处理)。 |
| SEL-003 | 取消选区高亮(如点击空白处)**不清空**选区缓冲;之后中键仍粘贴上一次选中的内容。 |
| SEL-004 | 选中结果为空字符串时,不覆盖选区缓冲中已有的内容。 |
| SEL-005 | 键盘扩展选区(如 `Shift+方向键`)后,同样写入选区缓冲。【待核实】 |
| SEL-006 | Linux:选区缓冲使用系统 PRIMARY selection,可与其他应用互通(在本终端选中 → 在浏览器中键粘贴,反之亦然)。 |
| SEL-007 | Windows:选区缓冲为应用内缓冲,同一进程内所有窗口、标签共享。 |
| SEL-008 | 设置项 `copy_on_select`(默认关闭):开启后,选中时**额外**写入系统剪贴板。选区缓冲行为不变。 |
| SEL-009 | 单击拖拽为普通选择;双击选词;三击选行。 |
| SEL-010 | `Ctrl+Alt` + 拖拽为块(矩形)选择。【待核实】 |
| SEL-011 | 双击选词时,词内额外包含的字符为:`@-./_~?&=%+#`(便于选中 URL 与路径)。【待核实】 |
| SEL-012 | 复制出的文本去除每行行尾空格;被换行折断的软换行行不插入换行符。【待核实】 |
| SEL-013 | 拖拽到终端区域边缘外时自动滚动并持续扩展选区。 |

## 2. 粘贴(PASTE)

剪贴板粘贴与选区缓冲粘贴共用**同一个**粘贴处理函数。

| ID | 规格 |
|---|---|
| PASTE-001 | 换行规范化:`\r\n` 与 `\n` 统一转换为 `\r`。 |
| PASTE-002 | 程序开启 bracketed paste 模式时,用 `ESC[200~` 与 `ESC[201~` 包裹粘贴内容。 |
| PASTE-003 | 未开启 bracketed paste 且文本含换行时,弹出确认对话框(可在设置中关闭)。【待核实】 |
| PASTE-004 | 无论是否开启 bracketed paste,粘贴内容中的 ESC(`0x1b`)一律移除,防止提前结束括号粘贴序列。 |
| PASTE-005 | 移除其他 C0 控制字符,仅保留 `\t` 及换行。【待核实】 |
| PASTE-006 | 粘贴内容不得被写入日志。 |

## 3. 鼠标与程序交互(MOUSE)

| ID | 规格 |
|---|---|
| MOUSE-001 | 程序开启鼠标上报(如 vim `mouse=a`、tmux、htop)时,鼠标事件交给程序,终端不做选区/粘贴。 |
| MOUSE-002 | 按住 `Shift` 时,忽略鼠标上报状态,由终端自己处理选区和粘贴。 |
| MOUSE-003 | 滚轮:主屏幕滚动回看;备用屏幕且程序未接管鼠标时,转换为方向键序列。【待核实】 |
| MOUSE-004 | 中键点击标签栏上的标签 = 关闭该标签;中键点击标签栏空白处 = 新建标签。【待核实】 |
| MOUSE-005 | 双击标签栏空白处新建标签;双击标签重命名。【待核实】 |

## 3.1 窗口装饰(WIN)

窗口使用**客户端装饰**:不使用系统标题栏,标题栏与窗口按钮由应用自绘,
视觉风格与终端内容统一(用户 2026-11-14 指定)。

| ID | 规格 |
|---|---|
| WIN-001 | 窗口无系统标题栏,内容区覆盖整个窗口(含原标题栏位置),不自留透明空隙。 |
| WIN-002 | 标题栏的空白区(标签条中标签与「+」以外的部分)为拖动区:按住左键并移动超过阈值可移动窗口。双击该空白区 = 新建标签(TAB/ MOUSE-005),不切换最大化。【2026-11-15 修订:原为「标题栏文字区」,标签条占据标题栏后文字区已不存在】 |
| WIN-003 | 窗口右上角自右向左依次为 关闭、最大化/还原、最小化 三个按钮。 |
| WIN-004 | 已最大化时,最大化按钮显示"还原"图标;该按钮点击在最大化/还原之间切换。 |
| WIN-005 | 平台不支持的控制按钮不显示且不占位;关闭按钮始终显示。 |
| WIN-006 | 每个平台上"窗口移动与按钮动作"只有一个执行者:系统接管时应用不重复执行。 |
| WIN-007 | 标题栏高度不计入终端网格行数;窗口缩放后 `stty size` 的行数与可见行数一致。 |
| WIN-008 | 程序通过 OSC 0/2 设置窗口标题时,标题栏文字随之更新。 |
| WIN-009 | 窗口未激活时标题文字变暗;关闭按钮悬停底色为红色,其余按钮为中性灰。 |

## 3.2 应用工具栏(TOOLBAR)

工具栏位于标签条与终端内容之间,布局参照 Konsole:左侧是窗口级操作,右侧是终端级操作。

| ID | 规格 |
|---|---|
| TOOLBAR-001 | 工具栏固定在标签条下方、终端内容上方,随窗口一起缩放。 |
| TOOLBAR-002 | 「新建标签页」执行新建标签并切换到它,与标签条上的「+」、`Ctrl+Shift+T` 同一路径。 |
| TOOLBAR-003 | 「复制」把当前高亮选区写入系统剪贴板,没有选区时不写剪贴板。 |
| TOOLBAR-004 | 「粘贴」把系统剪贴板内容写入终端,与中键粘贴选区缓冲共用同一套 PASTE 规则与多行确认。 |
| TOOLBAR-005 | 尚未实现功能的按钮(拆分视图、查找、更多菜单)置灰显示且不响应点击。 |
| TOOLBAR-006 | 工具栏高度不计入终端网格行数,窗口缩放后 `stty size` 的行数与可见行数一致。 |

## 3.3 标签页(TAB)

同一窗口内可以有多个标签,每个标签是一个独立的 PTY 会话(独立 shell、独立工作目录)。
标签共享同一份选区缓冲(SEL-007)与同一组窗口装饰。

| ID | 规格 |
|---|---|
| TAB-001 | 窗口至少有一个标签;启动时创建第一个标签。 |
| TAB-002 | 激活标签的终端内容占据标签栏以下的全部区域。非激活标签不渲染,但其进程继续运行、继续接收输出。 |
| TAB-003 | 切换到下一个标签(`Ctrl+Tab`)在末尾环绕到第一个。 |
| TAB-004 | 切换到上一个标签(`Ctrl+Shift+Tab`)在首个环绕到最后一个;只有一个标签时切换是空操作。 |
| TAB-005 | 关闭当前标签后,激活其右邻居;若关闭的是最后一个,则激活新的最后一个标签。 |
| TAB-006 | 关闭非当前标签不改变当前激活的标签。 |
| TAB-007 | 关闭最后一个标签时关闭整个窗口。 |
| TAB-008 | 标签标题显示程序通过 OSC 0/2 设置的窗口标题;程序未设置时显示默认标题 `RustSole`。 |
| TAB-009 | 切换到某个标签时,键盘焦点随之转移到该标签的终端。 |
| TAB-010 | 新建标签失败(PTY 无法分配)时不关闭已有标签,错误文字显示在窗口底部。 |
| TAB-011 | 每个标签右端显示关闭图标,点击关闭该标签(与 `Ctrl+Shift+W`、中键关闭同一路径,受 TAB-005/007 约束)。 |
| TAB-012 | 关闭图标只在指针悬停于图标本身时高亮,不改变标签的悬停底色。 |

## 4. 快捷键(KEY)

| ID | 规格 |
|---|---|
| KEY-001 | `Ctrl+Shift+C`:复制到系统剪贴板。 |
| KEY-002 | `Ctrl+Shift+V`:粘贴系统剪贴板。 |
| KEY-003 | `Shift+Insert`:粘贴选区缓冲。【待核实】 |
| KEY-004 | `Ctrl+C` 在终端内始终发送中断字符,不用于复制。 |
| KEY-005 | 方向键在应用光标模式(`APP_CURSOR`)下发送 `ESC O A/B/C/D`,否则发送 `ESC [ A/B/C/D`。 |
| KEY-006 | `Ctrl+Shift+T`:新建标签页。 |
| KEY-007 | `Ctrl+Shift+W`:关闭当前标签页。 |
| KEY-008 | `Ctrl+Tab`:切换到下一个标签页,末尾环绕到第一个。 |
| KEY-009 | `Ctrl+Shift+Tab`:切换到上一个标签页,首个环绕到最后一个。 |
| KEY-010 | 应用快捷键不得占用终端的控制字符(`Ctrl+T`=0x14、`Ctrl+W`=0x17 等),它们必须原样送达程序。 |
